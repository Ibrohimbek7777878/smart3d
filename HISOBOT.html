4. GibLab .project — texnik tafsilot

  • Format: XML root <project> + goods + sheet + operations CS/EL
  • Binar data blob: 15 bayt/record (opcode, size, count, part_id); LSTR packing, waste = cap − pos
  • Tekshiruv: Python parseri giblab_raskroy.py bilan round-trip bayt-ma-bayt teng; real faylda 55 detal / 11 karta / 0 xato
  • Yo'l: (o'qildi, buzilmadi) → Smart3D'ga moslashtirildi
