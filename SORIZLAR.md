## 20. Bugungi ishlar (2026-10-13)

### Material ID tizimi
- 8 xonali ID tizimi: `{prefix}{seq:06d}` (masalan: `10000121`)
- Kategoriya kodlari: LDS=10, LMD=11, MDF=40, HDF=50, AKR=60, OYN=70, BOSH=80
- `materials-index.json` — 1281 material, har birida `id`, `cat_code`, `aliases[]`, `search_text`

### Multi-til qidiruv (search.js)
- ID orqali qidiruv (8 xonali)
- SKU orqali qidiruv
- Kirill/lotin/eski kirill transliteratsiya
- Fuzzy matching (Levenshtein ≤ 2)
- Test natijalari:
  - `60000001` → 1 natija (ID)
  - `эггер` / `Egger` → 150 natija (kirill/lotin)
  - `kronoshpan` → 53 natija (transliteratsiya)
  - `WQ 3957` → 1 natija (SKU)

### Backend server (server/)
- Express.js + SQLite (better-sqlite3)
- JWT auth (register/login)
- Materials API (qidiruv, ID bo'yicha, narx yangilash)
- Fragments API (63 fragment)
- Orders API (yaratish, ro'yxat)
- Price history (narx o'zgarishlari)
- WebSocket real-time narx yangilanishi
- Test natijalari: login ✅, materials ✅, orders ✅, WebSocket ✅

### Frontend ulanish
- `app.js` — WebSocket ulandi (`ws://localhost:3000/ws`)
- Narx yangilansa sheetCatalog avtomatik yangilanadi
- Toast notification ko'rsatiladi

### Hujjatlar
- `app/README.md` — yangilandi (search engine, backend, API)
- `HANDOFF.md` — yangilandi (backend section, blockers yangilandi)
